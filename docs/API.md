# Доступ к публикациям и рейтинг

## Рейтинг профилей

Рейтинг составлен 20 ноября 2026 года по подписчикам среди найденных страниц о путешествиях по Коста-Рике. В поиске обработано 812 кандидатов Instagram и 727 кандидатов Facebook. Порог и тематическую проверку прошли 157 и 164 профиля соответственно. В рейтинг вошли первые 100 с каждой платформы.

### Ежедневное чтение архивов

GitHub Actions ищет ссылки на страницах архивов. Для Ticos A Pata, Vamos a Turistear и A Dónde Ir Costa Rica поиск использует также XML-индексы издателей. Они дают ссылки за пределами первой страницы архива. Actions читает до пяти страниц каждого подтверждённого архива за запуск. Сначала идут непрочитанные и обновлённые страницы, внутри этой группы выше стоят ссылки со свежим `lastmod`, если издатель его указал. Для ссылок без даты сохраняется порядок выдачи на сайте. `lastmod` показывает заявленное обновление страницы. Дата публикации извлекается отдельно. Плановая перепроверка прочитанной статьи доступна через 30 дней, а более свежий `lastmod` позволяет прочитать её раньше.

В артефакте `atlas-candidates` файл `publisher-review.json` показывает число найденных и прочитанных страниц по каждому архиву. В это покрытие входят статьи, на которые атлас уже ссылается. Файл хранит метаданные прочитанных страниц, найденные ссылки на соцсети, темы и совпадения с карточками. В массиве `socialCandidates` ссылки из всех сохранённых статей сводятся по адресу публикации. Для каждой ссылки сохраняются статьи, где её нашли, и профили, связанные с этими архивами. Авторство и доступность поста проверяются по прямой ссылке. Список кандидатов в `refresh.json` показывает новые ссылки для проверки.

Счётчик архивов показывает сайты издателей. Счётчики Instagram и Facebook по-прежнему ведутся по прямым публикациям на этих площадках. Кандидат на новое место проверяется редакционно. Например, текст Hotel Belmar связал Finca Madre Tierra с отелем, а отдельная страница фермы дала доступные форматы визита и контакт. [Ежедневные прогоны](https://github.com/Paldd/costa-rica-travel-atlas/actions/workflows/refresh.yml)

## Текстовые выгрузки с ограничением расхода

1. Страница в рейтинге служит единицей покрытия. Для начала достаточно проверить формат результата на нескольких страницах каждой платформы. Для большого прогона берём профили с пробелами в выборке и добавляем лимит `resultsLimit` на профиль. Instagram поддерживает `dataDetailLevel: "basicData"`. В Facebook оставляем выключенной расшифровку видео. [Схема Instagram](https://apify.com/apify/instagram-post-scraper/input-schema) · [Схема Facebook](https://apify.com/apify/facebook-posts-scraper/input-schema)
2. В API запуска задаём `maxTotalChargeUsd` для каждого задания. На Free по прайсу от 21 ноября 2026 года базовые события стоят $1,70 за 1 000 постов Instagram и $5 за 1 000 Facebook. У Facebook запуск стоит $0,001, а применение фильтра дат может добавить $2 за 1 000 результатов. Перед запуском проверяем текущие ставки и доступный остаток в кабинете. [Instagram](https://apify.com/apify/instagram-post-scraper/pricing) · [Facebook](https://apify.com/apify/facebook-posts-scraper/pricing) · [Лимит запуска](https://docs.apify.com/api/v2/actors-runs-post)
3. По пять постов на каждый из 200 профилей стоят примерно $3,35 по этому базовому тарифу при одной задаче на платформу, без доплат и при наличии всех 1 000 результатов. Десять на профиль стоят около $6,70, сто на профиль — около $67. Если сначала закрывать пробел в Facebook, пять постов с каждой из 100 страниц дадут до 500 текстов примерно за $2,50 без дополнительных событий. Для исторического просмотра нужны фактические объёмы лент, диапазоны доступных дат и отдельные лимиты. Повторные прогоны без проверенной границы могут снова оплатить уже полученные посты.
4. Из датасета загружаем URL и идентификатор поста, страницу, дату и подпись. Короткий экспорт снижает объём передачи и локального анализа. Ставка за результат зависит от акторов и событий, запрошенных на этапе сбора. [Поля датасета](https://docs.apify.com/api/v2/dataset-items-get)
5. Храним локально объём полученных данных, даты первой и последней публикации в каждом профиле, пропуски и статус задания. Сверяем уникальные публикации и упоминания с атласом. Кандидаты проходят проверку у местного автора, оператора или управляющей организации. В атлас попадают ссылка, собственное описание и доказуемые координаты. Условия применения автоматизированного доступа сверяются с правилами источников. [Правила Meta об автоматизированном сборе](https://about.fb.com/news/2021/04/how-we-combat-scraping/)

Скрипт читает доступные JSON-файлы и создаёт локальный отчёт с покрытием профилей, тематическими сигналами, совпадениями и кандидатами. Можно подать один или несколько экспортов. Совпадение по названию служит указателем для проверки, особенно при распространённых названиях водопадов и пляжей.

```sh
python3 scripts/review_social_posts.py \
  --instagram .cache/instagram-export.json \
  --facebook .cache/facebook-export.json \
  --out .cache/social-review.json
```
