# Проверка доступа к публикациям

Сверка проведена 20 ноября 2026 года. Исходный список включает по 100 публичных аккаунтов Instagram и Facebook. Для типовых запросов учитывался реально полученный ответ, для каждого профиля — доступный материал.

| Источник | Что проверено | Покрытие |
| --- | --- | --- |
| Локальный Meta Graph API через MCP | Инвентарь рекламных аккаунтов и разрешённые запросы к собственным Instagram и Facebook-активам бизнеса. Реестр операций не содержит сторонние ленты, Business Discovery или Page Published Posts | Соединение с API живое. Ленты 200 внешних аккаунтов недоступны через установленный коннектор |
| Instagram Business Discovery | Meta описывает чтение данных о сторонних профессиональных аккаунтах через ID профессионального аккаунта приложения и требуемые разрешения | Нужно отдельное подключение, проверка scopes и успешный пробный запрос к стороннему профессиональному аккаунту. Охват личных аккаунтов этим интерфейсом не подтверждён |
| Facebook Page Published Posts | Требования Meta к доступу за пределами управляемых страниц | Возможность чтения ленты каждой сторонней страницы зависит от приложения, токена и разрешения Page Public Content Access |
| Meta Content Library | Проверены описание и процесс подачи заявки в Research Tools Manager | Для проекта доступ не оформлен. Право на доступ определяется условиями Meta |
| Windsor | Проверен список подключённых источников | Соединение требует авторизации |
| Доступная выборка Instagram | Точечные образцы подписей к постам из предыдущего публичного исследования профилей | 582 публикации из 98 профилей, у двух подтверждена только карточка. Подписи были обрезаны в исходной выборке. Полная история аккаунтов недоступна |
| Facebook | Для всех 100 страниц подтверждены адрес и публичное описание | Посты за период массово не получены. Счётчик подписчиков и описание не подтверждают доступ к ленте |

Для каждой строки раздела «Источники» показан её реальный объём материала. Программа импорта ищет подтверждённые названия в уже доступном локальном образце. Сохраняются публичные ссылки на профили и релевантные посты, количество просмотренных записей и дата. Содержание публикаций, история посещений, credentials и пользовательские файлы отсутствуют в репозитории. Спорный тег или подпись остаётся материалом для тематической проверки, а правила входа и дороги подтверждаются отдельно.

## Источники для расширения

| Зачем | Источники |
| --- | --- |
| Допуск, бронирование, карта парка | SINAC, ACG, муниципалитеты, официальные страницы и системы билетов |
| Маршрут и трек | Парк или организатор, Asociación Mar a Mar, местный уполномоченный проводник, открытая схема с лицензией |
| Условия конкретного кемпинга, проката или тура | Оператор, публичная карточка и изменения в правилах. В том числе разрешение на установку крышной палатки на конкретном месте |
| Погода и дорожные события | IMN, CNE, MOPT, предупреждения управляющих организаций |
| Реальный опыт | Датированные отчёты Wikiloc, авторские блоги, публичные публикации, свежие отзывы и карта. Точные цены или проходимость из отзывов используются с датой |
| Поиск и разнообразие | Visit Costa Rica, региональные муниципальные каталоги, национальные и местные туроператоры, OpenStreetMap, Costa Rica Camping Guide, Camping.cr, специализированные школы и организаторы |

Публичный процесс пополнения читает перечисленные в `data/feeds.json` сайты и фиксирует незнакомые ссылки, условия чтения и контрольную сумму документа. Отдельный редакционный этап сверяет кандидатов и вносит изменения. Чтение постов через API можно подключить после подтверждения разрешений и соответствия сценария правилам Meta.
