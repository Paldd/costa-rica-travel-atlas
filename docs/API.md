# Доступ к публикациям и рейтинг

## Рейтинг профилей

Рейтинг составлен 20 ноября 2026 года по подписчикам среди найденных страниц о путешествиях по Коста-Рике. В поиске обработано 812 кандидатов Instagram и 727 кандидатов Facebook. Порог и тематическую проверку прошли 157 и 164 профиля соответственно. В рейтинг вошли первые 100 с каждой платформы.

У сотого Instagram-профиля было 26 861 подписчиков, у сотой страницы Facebook — 31 394. Одна оценка Instagram округлена так же, как в источнике. Снимок хранит дату, место в рейтинге, тип страницы и ссылку на источник числа подписчиков. [Рейтинг в атласе](https://paldd.github.io/costa-rica-travel-atlas/#sources) · [Снимок рейтинга](../data/profile-ranking.tsv)

## Проверка API 21 ноября 2026 года

| Источник | Результат |
| --- | --- |
| Локальный Meta Graph API через MCP | Повторно получен живой ответ на выборку инвентаря управляемых рекламных аккаунтов. Проверка каталога операций для Instagram Business Discovery и Facebook Page Published Posts вернула, что соответствующие типы объектов не поддерживаются. |
| Instagram Business Discovery | Meta документирует получение данных сторонних профессиональных аккаунтов при подходящем подключении и разрешениях. Успешный запрос к стороннему профилю в этой конфигурации пока отсутствует. |
| Facebook Page Published Posts | Чтение чужих страниц зависит от прав приложения и токена. Для публичного контента вне управляемых страниц Meta документирует Page Public Content Access. |
| Meta Content Library | Доступ для проекта отсутствует. Meta рассматривает заявки на доступ через Research Tools Manager. |
| Windsor | Подключение источника требует авторизации. |

## Фактически просмотренные публикации

| Платформа | Фактическое покрытие |
| --- | --- |
| Instagram | В локальном публичном образце есть 582 строки с подписями для 98 профилей. После устранения повторных ссылок осталось 579 уникальных публикаций. Подписи могут быть обрезаны. Два профиля представлены карточками без образца постов. |
| Facebook | В исходном исследовании прочитаны описания всех 100 страниц. В браузере открыто пять отдельных публикаций из трёх страниц. В каталог вошли дорожный совет Visit Costa Rica, три материала Qué Buen Lugar и видео Hacienda Orosi. [Реестр просмотренных постов](../data/public-posts.tsv) |

Раздел «Источники» показывает дату замера аудитории и объём доступных данных по каждому профилю. Для просмотренных публикаций Facebook указаны прямые ссылки и даты проверки. Импорт Instagram извлекает адреса публикаций из уже доступного локального образца. Разные авторы и обзоры одного места могут ссылаться на общий пост. Его адрес учитывается один раз при подсчёте уникальных публикаций. Правила, цены, входы и дорожные сведения подтверждаются у владельца, парка или местного ведомства.

## Источники для расширения

| Зачем | Источники |
| --- | --- |
| Допуск, бронирование, карта парка | SINAC, ACG, муниципалитеты, официальные страницы и системы билетов |
| Маршрут и трек | Парк или организатор, Asociación Mar a Mar, местный уполномоченный проводник, открытая схема с лицензией |
| Условия конкретного кемпинга, проката или тура | Оператор, публичная карточка и изменения в правилах. В том числе разрешение на установку крышной палатки на конкретном месте |
| Погода и дорожные события | IMN, CNE, MOPT, предупреждения управляющих организаций |
| Реальный опыт | Датированные отчёты Wikiloc, авторские блоги, публичные публикации, свежие отзывы и карта. Точные цены или проходимость из отзывов используются с датой |
| Поиск и разнообразие | Visit Costa Rica, региональные муниципальные каталоги, национальные и местные туроператоры, OpenStreetMap, Costa Rica Camping Guide, Camping.cr, специализированные школы и организаторы |

Публичный процесс пополнения читает перечисленные в `data/feeds.json` сайты и фиксирует незнакомые ссылки, условия чтения и контрольную сумму документа. Отдельный редакционный этап сверяет кандидатов и вносит изменения. Чтение постов через API можно подключить после подтверждения разрешений и соответствия сценария правилам Meta.
