# Атлас Коста-Рики

## Задача

Довести атлас до веб-платформы для регулярных поездок из Коста-Рики. Семья выбирает подходящий выезд на выходные или в отпуск, собирает собственный план по дням и берёт в дорогу остановки, координаты, контакты, экипировку и альтернативы. Каталог также поддерживает одиночные поездки, друзей и мужские компании. Для каждой поездки видны длительность, ограничения и дата последней сверки.

Публичный каталог и личные планы связаны через карточки мест. Семейные записи о посещении, заметки и даты хранятся в браузере. Семья сама передаёт скачанный план. Подборки из ChatGPT и Claude используются для поиска мест и сверки ссылок. Факт посещения отмечают по известной семье поездке. В открытых карточках публикуются условия и источники, пригодные для любого путешественника.

Границы зон служат для планирования. Например, Гуанакасте встречается и в зоне Никоя, и на северном побережье. Для поездок через несколько зон карточка указывает базовый район и каждую остановку.

## Классификация

| Фильтр | Значения и правило |
| --- | --- |
| Объект | Место, конкретный маршрут, экспедиция с расписанием по дням |
| Страна | Коста-Рика, Панама, Никарагуа. Поездка с пересечением отображается в обеих странах |
| Длительность | Полдня, один день, два дня, три дня, четыре–пять дней, шесть–семь дней, восемь и больше |
| Состав | Соло, друзья, мужская компания, семья без детей, с малышами, с детьми 6–11, с подростками |
| Подъезд | Без машины, обычная машина, высокий клиренс, 4×4, трансфер, лодка |
| Ночёвка | Дневная поездка, наземная палатка, палатка на крыше, глэмпинг, домик/лодж, приют, уточнить |
| Сложность | Лёгкая, умеренная, сложная, экспедиционная. Сложность зависит от подъёма, продолжительности и логистики |
| Ландшафт | Облачный и дождевой лес, открытые саванны и сухой лес, горы, вулканы, реки, озёра, карибские и тихоокеанские пляжи, белый и чёрный песок |
| Суша | Пешие тропы, восхождения, трейлраннинг, MTB, gravel, шоссе и e-bike, автомобильные маршруты и разрешённый оффроуд, кемпинг, глэмпинг, багги, канопи и каньонинг |
| Вода | Купание, термальные источники, SUP, каяк, пакрафт, рафтинг, свои лодки, лодочные прогулки, катамараны, рыбалка, сёрфинг и школы |
| Дополнения | Смотровые площадки, кофейни и экскурсии на кофейные фермы, жильё и запасные варианты |

Возрастные группы помогают подобрать темп поездки. Возраст участия, рост, плавание и сопровождение указываются по правилам конкретного оператора, если источник их публикует. Оценка пригодности для семей в каталоге редакционная. Доступ для легковой и 4×4 проверяется отдельно. Для метки «Палатка на крыше» требуется подтверждение стоянки, на которой оператор допускает ночёвку в машине или конкретно крышные палатки. Обычный палаточный кемпинг остаётся отдельным вариантом.

## Карточка

- Русское название, исходное название на испанском или английском, регион и точка для карты.
- Тип, длительность, условная сложность, активности, состав группы, подъезд и ночёвка.
- Краткая характеристика, последовательность остановок, если она нужна, и явные развилки.
- Где резервировать доступ, требуется ли сопровождение, где уточнить дорожную обстановку, возраст и состояние воды.
- Сколько времени занимает само занятие, сколько добавляют встреча, дорога, ожидание и пересадки. Для экспедиции указываются отдельные дни и участки.
- Что взять с собой, что выдают на месте, какие документы, билеты, разрешения или данные нужны для записи. Публикуются телефоны, WhatsApp, почта и страницы бронирования, которые организатор указал для посетителей.
- Фотографии места с подписью и авторством, ссылки на опубликованные видео и фотоотчёты. Снимок окрестностей подписывается с указанием места съёмки, а сгенерированное изображение всегда называется иллюстрацией.
- Источники по полям, дата сверки, при возможности ссылка на официальный трек или карту, ссылка на отзывы.
- Неподтверждённые расстояния, цены, сезонные проезды, минимальный возраст и разрешение на ночёвку остаются пустыми или помечены «уточнить». Планирование длительности составного маршрута помечено как редакционное.

## Данные и публикация

| Блок | Поля и поведение |
| --- | --- |
| Карточка | Постоянный `id`, `kind`, базовый `region`, дополнительные `regions` и `countries` для составных поездок, исходное название, длительность в днях, расстояние в километрах по возможности, список отметок активности, аудитории, подъезда и ночёвки |
| План | Текст маршрута, список этапов с номером и описанием, ссылки на карточки остановок и первоисточники каждого этапа. День и официальный этап различаются |
| Условия | Ограничения для заезда, участия детей и доступа к воде, способ уточнения, дата сверки в формате `YYYY-MM-DD` |
| Источник | Постоянный `id`, адрес HTTPS, заголовок, тип источника и короткое описание сведений, которые он подтверждает |
| Медиа | `photos` ссылается на реестр файлов, подписей, авторов и лицензий. `videos` ссылается на проверенные открытые материалы. Карточка показывает первый снимок в шапке и подписывает остальные в описании |
| Соцпрофиль | Канонический URL, площадка, факт просмотра карточки и число просмотренных публичных публикаций. Связь с карточками хранится отдельно от описания условий |
| Сборка | Python формирует `atlas.json`. React отображает каталог и фильтры, Vite собирает сайт. GitHub Pages публикует сборку после проверки ID, ссылок, этапов и регрессионных примеров поиска |
| Чек публикации | Живая страница, `atlas.json` с ожидаемыми количествами, `release.json` с SHA опубликованного коммита, рабочие глубокие ссылки |

Новый материал идёт от кандидата к проверенной карточке по открытому URL и предмету подтверждения. Дубли определяются по оператору, району, назначению и варианту маршрута. Два маршрута к одной достопримечательности допускаются, если у них различаются реальные пути, входы или условия. При редакционном обновлении сохраните дату сверки карточки в `data/checks.tsv` двумя полями через табуляцию, ID и `YYYY-MM-DD`. Не обновляйте общую дату исходного выпуска при проверке отдельного объекта.

## Интерфейс

- Каталог с поиском по названию на русском и исходном языке, району, типам активности и подписи места. Фильтры пересекаются и сохраняются в URL.
- Представления списком и на карте используют общие фильтры. Карта показывает места и приблизительные ориентиры, группирует близкие точки и даёт открыть карточку. Для выбранного маршрута она показывает остановки и подтверждённую геометрию там, где доступен источник.
- Из каталога открывается отдельная карточка с постоянным адресом. На мобильном экране навигация, фильтры и карточка доступны с клавиатуры и через сенсорный интерфейс.
- Раздел «Экспедиции» с готовыми последовательностями на 2, 3, 5, 7 и больше дней. Для регулируемых зон доступны исходные правила и альтернатива до закрытого участка.
- «Сохранённое» хранит закладки в текущем браузере.
- «Мои поездки» хранит несколько планов. Можно начать с пустого плана или взять готовую экспедицию за основу. Карточки переносятся между днями, меняют порядок и получают отметку о посещении. Дата начала и заметки сохраняются в браузере.
- План скачивается в файл, который открывается без сети и содержит контакты, порядок остановок и координаты. Ссылки на живые карты и оригинальные карточки открываются при наличии связи.
- В маршруте через границу указаны оба пункта оформления, временная зона, план пересадки, документы по каждому пассажиру, отдельная проверка разрешений на машину и запасной вариант с ночёвкой. Время в очереди и сезонные отмены учитываются в плане дня.
- Раздел «Источники» показывает покрытие 200 аккаунтов, разницу между доступом к профилю и постам, дату и источники проверок. Кандидат из публикации остаётся кандидатом до сверки.

## Наполнение

1. **Исходный список.** Сверить 100 Instagram и 100 Facebook по платформе и каноническому адресу. Учитывать фактический доступ к публикациям по каждому аккаунту. Для доступных выборок извлекать названия мест, даты, ссылку на пост и связь с конкретной карточкой. Описания профилей учитываются как отдельный вид сигнала.
2. **Первичная сверка.** Для охраняемых территорий применять SINAC и соответствующую Área de Conservación, для конкретных туров и ночёвок — текущие условия оператора, для маршрута El Camino — Asociación Mar a Mar, для активностей и мест — ссылки ICT, муниципалитетов, организаторов, общин и спортивных парков.
3. **Карты и впечатления.** Установить точку и ссылку на карту. Публичные отзывы и отчёты путешественников добавлять как датированные наблюдения, когда они дают конкретику о подъезде, покрытии, времени и удобствах. Социальная публикация и метка на карте не подтверждают правила доступа.
4. **Разрешения и права.** Получать посты через разрешённый API, предоставленные владельцами выгрузки или открытый просмотр по ссылке. Сохранять краткие собственные описания и ссылки. Имена публичных проектов допустимы. Тексты постов, фотографии, платные треки, вход через частные территории и закрытые подходы не переносить в публичный каталог без соответствующих прав.
5. **Повторная проверка.** Регулярное задание читает реестр доступных открытых источников, сравнивает наличие и ссылки, сохраняет кандидатов для проверки. Публикация правил, доступа, детских ограничений и геометрии маршрута требует подтверждения источника. Записи со сменившимися условиями помечаются до следующего релиза.
6. **Дополнение карточек.** Сверять уже опубликованные карточки по карте, длительности, экипировке, документам, контактам, фотографиям, видео и местным отчётам. Полезные наблюдения из нескольких источников привязывать к месту и конкретному условию. Для недоступного оригинала фото или видео сохранять только проверенную ссылку, если она помогает спланировать поездку.

## Порядок разработки

Первая поставка включает каталог, карточки, разделы экспедиций, источников и закладок, GitHub Pages и регулярный сбор кандидатов. Исходные таблицы версионируются вместе с кодом. Публикация привязана к основной ветке.

Отдельные этапы расширения охватывают новые районы и языки, историю изменений условий, лицензированные GPX, многоисточниковые впечатления, проверенные политики кемпингов для автопалаток, свежие официальные уведомления и разрешённый импорт постов после получения соответствующего доступа. Приоритет роста определяется пробелами в регионах и активностях.

## Критерии приёмки

1. Сайт доступен по публичному URL. Фильтры, глубокие ссылки, карточки, карта и закладки проверены на компьютере и мобильном экране.
2. Все отображаемые записи имеют уникальный ID, район, понятное содержание, хотя бы один тематический источник и дату сверки. Маршрут и география дублирующих названий различимы.
3. Экспедиции содержат дни, остановки, подъезд, ночёвку и точки принятия решений. Походы по ограниченным территориям показывают правила, которые нужно перепроверить.
4. Для всех 200 соцпрофилей указан объём реально просмотренных данных. Свежий статус API приведён отдельно. Страницы, посты, отзывы и юридический доступ считаются разными видами доказательства.
5. Доступно расписание пополнения и проверяемый результат хотя бы одного запуска. Состав источников, покрытие и непроверенные свойства видны читателю.
6. В проработанной карточке есть понятный способ записаться или уточнить условия, продолжительность поездки и отдельных занятий, список вещей, требования к участникам и источники. Для доступных фото и видео проверены изображённое место, права на фото и работа ссылки. Снимки с неизвестными правами доступны по ссылке на оригинальную публикацию, если она открыта.

7. На компьютере и телефоне проверен полный семейный сценарий. Пользователь выбирает поездку по фильтрам, создаёт план, меняет дни, перезагружает страницу, открывает карту остановки и скачивает файл для дороги. Шаблон экспедиции переносит дни и исходные карточки.
8. У приграничного маршрута есть обе страны, пины официального пункта и дальнейших остановок, миграционные и таможенные ссылки, тип транспорта и вариант для семьи без машины там, где действующий перевозчик подтверждён. Маршрут в частной машине показывает порядок оформления при выезде, въезде и возвращении.
9. Полнота проверяется по регионам, форматам ночёвки и каждой запрошенной активности. Для каждой зоны доступны короткие выезды и сочетания нескольких занятий. Где варианты подтверждаются источниками, есть дистанции порядка 10, 30, 50 и 100 км, а также поездки на 1, 2, 3, 5 и 7 дней. Пробелы отражаются в реестре источников и определяют следующие выезды и проверки.
