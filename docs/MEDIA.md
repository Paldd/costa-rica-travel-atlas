# Иллюстрации и карта

- Ареналь, высокогорье Чиррипо, песчаная коса Увиты и открытые горы для карточки Сабана Ока — самостоятельные иллюстрации, созданные для этого сайта с помощью ImageGen. Документальные фотографии и карты доступны по ссылкам на источники в карточках.
- Контур на карте взят из открытых данных Natural Earth, набор Admin 0 Countries, масштаб 1:50m. Маркеры показывают географические районы каталога. [Данные](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson) · [Условия использования](https://www.naturalearthdata.com/about/terms-of-use/)
- Подробные карты показывают остановки, справочные точки и порядок прохождения. Подложка и точки, отмеченные источником OpenStreetMap, используют данные © участники OpenStreetMap по лицензии ODbL. Происхождение ориентиров указано в таблице `data/map-points.tsv`, а исходные карты и треки доступны по ссылкам в карточках. [OpenStreetMap](https://www.openstreetmap.org/copyright) · [Лицензия ODbL](https://opendatacommons.org/licenses/odbl/1-0/)
