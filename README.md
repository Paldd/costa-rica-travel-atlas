# Атлас Коста-Рики

Открытый каталог маршрутов, мест и экспедиций. Подбирает поездку по району, занятиям, составу группы, транспорту, длительности, сложности и ночёвке. Карточки содержат план, условия и ссылки на первоисточники и карту.

[Открыть атлас](https://paldd.github.io/costa-rica-travel-atlas/) · [Техническое задание](docs/TZ.md) · [Аудит API](docs/API.md) · [Иллюстрации и карта](docs/MEDIA.md)

## Запуск

Требуются Node.js 22 или новее и Python 3.10 или новее.

```sh
npm ci
npm run check
npm run dev
```

Сборка GitHub Pages подготавливается командой `npm run build`. Выходные данные находятся в `dist/`. Адрес отдельной карточки использует фрагмент URL и открывается напрямую на GitHub Pages.

## Как добавлять данные

Маршруты и места находятся в `data/catalog*.tsv`, многодневные программы — в `data/expeditions.json`, ссылки и их назначение — в `data/sources.tsv`. Файл `data/profile-ranking.tsv` содержит два рейтинга по 100 профилей с датой замера и источником числа подписчиков. Доступные данные Instagram находятся в `data/social-coverage.json`, прочитанные посты Facebook — в `data/public-posts.tsv`. Реестр `data/profile-publishers.tsv` связывает профили с подтверждёнными сайтами и их архивами. Допустимые значения фильтров находятся в `src/catalog.js`.

Если меняются условия дороги, ночёвки, возраст, вода или доступ к тропе, информация с сайта парка или оператора имеет приоритет. Отзывы и треки участников показывают личный опыт на дату публикации. Сводка источников находится на сайте в разделе «Источники».

## Обновление

GitHub Actions ежедневно запускает чтение открытых каталогов. Список источников настраивается в `data/feeds.json`. Результат сохраняется как артефакт `atlas-candidates` под соответствующим запуском. Туда входят статусы источников и новые ссылки для редакционной сверки.

Локально тот же шаг доступен через `python3 scripts/refresh.py`. Публичный релиз обновляется после внесения подтверждённых данных в основную ветку. Публикация содержит контрольный `release.json` с SHA исходного коммита.
