# Атлас Коста-Рики

Платформа для поездок по Коста-Рике и через её границы с Панамой и Никарагуа. Атлас подбирает места, маршруты и экспедиции по стране, району, занятиям, составу группы, транспорту, длительности и ночёвке. В разделе «Мои поездки» можно составить свой план по дням, сохранить заметки и скачать координаты и контакты для дороги. Личные планы сохраняются в браузере.

## Запуск

Требуются Node.js 22 или новее и Python 3.10 или новее.

```sh
npm ci
npm run check
npm run dev
```

Сборка GitHub Pages подготавливается командой `npm run build`. Выходные данные находятся в `dist/`. Адрес отдельной карточки использует фрагмент URL и открывается напрямую на GitHub Pages.

## Как добавлять данные

Маршруты и места находятся в `data/catalog*.tsv`, многодневные программы — в `data/expeditions.json`, ссылки и их назначение — в `data/sources.tsv`. Файл `data/profile-ranking.tsv` содержит два рейтинга по 100 профилей с датой замера и источником числа подписчиков. Доступные данные Instagram находятся в `data/social-coverage.json`, прочитанные посты Facebook — в `data/public-posts.tsv`. Реестр `data/profile-publishers.tsv` связывает профили с подтверждёнными сайтами и их архивами. Допустимые значения фильтров находятся в `src/catalog.js`.

Если меняются условия дороги, ночёвки, возраст, вода или доступ к тропе, информация с сайта парка или оператора имеет приоритет. Отзывы и треки участников показывают личный опыт на дату публикации. Сводка источников находится на сайте в разделе «Источники».

## Обновление

GitHub Actions ежедневно читает открытые каталоги и страницы подтверждённых архивов. Список источников находится в `data/feeds.json`. Для разделов сайта задаются префиксы путей `paths`. Для отдельных программ на корневых адресах доступны точные пути `exactPaths`. Артефакт `atlas-candidates` содержит два отчёта. В `refresh.json` указаны статусы источников и новые ссылки, а в `publisher-review.json` — открытые архивные страницы, темы и совпадения для сверки.

Локально запустите `python3 scripts/refresh.py`, затем `python3 scripts/review_publisher_archives.py`. Публичный релиз обновляется после внесения подтверждённых данных в основную ветку. Публикация содержит контрольный `release.json` с SHA исходного коммита.
