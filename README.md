# Атлас Коста-Рики

Платформа для поездок по Коста-Рике и через её границы с Панамой и Никарагуа. Атлас подбирает места, маршруты и экспедиции по стране, району, сочетанию занятий, составу группы, транспорту, длительности и ночёвке. В разделе «Мои поездки» можно составить план по дням, сохранить заметки и скачать HTML с условиями поездки и GPX с точками и доступными дорожными или пешими участками. Личные планы сохраняются в браузере.

## Запуск

Требуются Node.js 22 или новее и Python 3.10 или новее.

```sh
npm ci
npm run check
npm run dev
```

Сборка GitHub Pages подготавливается командой `npm run build`. Выходные данные находятся в `dist/`. Адрес отдельной карточки использует фрагмент URL и открывается напрямую на GitHub Pages.

## Как добавлять данные

Маршруты и места находятся в `data/catalog*.tsv`, многодневные программы — в `data/expeditions.json` и `data/expeditions-*.json`. Источники хранятся в `data/sources.tsv` и `data/sources-*.tsv` с общими идентификаторами. Файл `data/profile-ranking.tsv` содержит два рейтинга по 100 профилей с датой замера и источником числа подписчиков. Образец подписей Instagram находится в `data/social-coverage.json`. Проверенные оригиналы Instagram и Facebook добавляются в `data/public-posts.tsv`. Реестр `data/profile-publishers.tsv` связывает профили с подтверждёнными сайтами и их архивами. Допустимые значения фильтров находятся в `src/catalog.js`.

Результаты открытия лент из рейтинга хранятся в `data/profile-browser-checks.tsv`. У каждой проверки есть дата и видимый результат. Прямые ссылки на отдельно прочитанные публикации остаются в реестре постов.

Если меняются условия дороги, ночёвки, возраст, вода или доступ к тропе, информация с сайта парка или оператора имеет приоритет. Отзывы и треки участников показывают личный опыт на дату публикации. Сводка источников находится на сайте в разделе «Источники».

## Обновление

GitHub Actions ежедневно читает открытые каталоги и страницы подтверждённых архивов. Список источников находится в `data/feeds.json`. Для разделов сайта задаются префиксы путей `paths`. Явно заданные пути `exactPaths` также попадают в очередь проверки, если сайт разрешает их чтение. Для подтверждённого архива в список можно включить путь самой стартовой страницы, когда на ней опубликован полный материал или программа. Артефакт `atlas-candidates` сохраняет три файла. В `refresh.json` указаны статусы источников и новые ссылки. В `publisher-review.json` собраны открытые страницы, темы и совпадения для сверки. В `publisher-review-coverage.json` есть счётчики последнего обхода и накопленный список прочитанных страниц для раздела «Источники». Для каждой ссылки сохраняется дата успешной проверки.

Локально запустите `python3 scripts/refresh.py`, затем `python3 scripts/review_publisher_archives.py`. Публичный релиз обновляется после внесения подтверждённых данных в основную ветку. Публикация содержит контрольный `release.json` с SHA исходного коммита.
